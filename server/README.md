# ContractIQ Backend Server

FastAPI-based backend for Contract Obligation Management Platform.

## Features
- JWT Authentication
- Role-Based Access Control (RBAC)
- PostgreSQL Database
- RESTful API

## Installation

```bash
pip install -r requirements.txt
```

## Run Server

```bash
uvicorn main:app --reload --port 8000
```

## API Documentation

Once running, visit:
- Swagger UI: http://localhost:8000/docs
- ReDoc: http://localhost:8000/redoc
