# Render Deployment Guide for ContractIQ

## Overview
This guide covers deploying the ContractIQ application with authentication (login/register) to Render.

## Pre-Deployment Checklist

### 1. Environment Variables Configuration

#### Frontend (React Client)
The following environment variables are configured in `render.yaml`:
- `VITE_API_URL`: Backend API URL
- `VITE_API_BASE_URL`: Backend API base URL

Both default to: `https://contractiq-server.onrender.com`

#### Backend (FastAPI Server)
Configure these in Render dashboard:
- `DATABASE_URL`: PostgreSQL connection string (required)
- `TOKEN_SECRET`: Auto-generated by Render (recommended)
- `SECRET_KEY`: Compatibility secret key (required)
- `ALGORITHM`: HS256 (default)
- `ACCESS_TOKEN_EXPIRE_MINUTES`: 480 (default)

### 2. Database Setup
1. Create a PostgreSQL database in Render
2. Copy the database connection string
3. Add it as `DATABASE_URL` environment variable in backend service

### 3. CORS Configuration
The backend is configured to allow requests from:
- `http://localhost:5173` (local development)
- `http://127.0.0.1:5173` (local development)
- `https://contract-obligation-b-07-26.onrender.com` (existing frontend)
- `https://contract-obligation-frontend.onrender.com` (new frontend)

## Deployment Steps

### 1. Push to GitHub
```bash
git add .
git commit -m "Configure for Render deployment with authentication fixes"
git push origin Group-A-feature/settings-module-pragna
```

### 2. Deploy to Render
1. Go to [Render Dashboard](https://dashboard.render.com)
2. Click "New +" → "Blueprint"
3. Connect your GitHub repository
4. Select the `render.yaml` file
5. Review configuration and deploy

### 3. Configure Environment Variables
After deployment:
1. Go to your backend service in Render
2. Add `DATABASE_URL` with your PostgreSQL connection string
3. Add `SECRET_KEY` with a secure random string
4. Restart the backend service

## Troubleshooting

### Issue: CORS Errors
**Solution**: Ensure your frontend URL is added to CORS configuration in `server/src/main.py`

### Issue: Authentication Fails
**Solution**: 
1. Check backend logs in Render
2. Verify `DATABASE_URL` is correct
3. Ensure `SECRET_KEY` is set
4. Check that user exists in database

### Issue: Token Not Stored
**Solution**: 
1. Check browser console for JavaScript errors
2. Verify localStorage/sessionStorage is accessible
3. Check that `Auth.js` is using correct storage keys

### Issue: API Connection Failed
**Solution**:
1. Verify `VITE_API_URL` is set correctly
2. Check backend service is running
3. Test backend health endpoint: `https://contractiq-server.onrender.com/health`

### Issue: Role Mismatch
**Solution**: 
- Ensure the role selected during login matches the role assigned during registration
- Check user role in database

## Security Notes

1. Always use strong `SECRET_KEY` in production
2. Use HTTPS for all connections
3. Never commit `.env` files
4. Rotate secrets periodically
5. Monitor backend logs for authentication failures
